# vX.Y.Z — 한 줄 제목

## GitHub 게시용 요약

사용자가 가장 크게 체감할 변화를 두세 문장으로 설명합니다.

### 주요 변경

- 사용자가 새로 할 수 있는 일과 달라진 동작을 적습니다.
- 내부 구현이나 커밋 제목을 그대로 나열하지 않습니다.

### 업데이트 안내

영향받는 사용자와 설치·업데이트·마이그레이션 방법을 적습니다. 필요한 작업이 없다면 그 사실을 분명히 씁니다.

### 검증 요약

GitHub에서 빠르게 읽을 수 있도록 직접 확인한 핵심 검증만 요약합니다.

### 알려진 제한

지원 범위, 호환성, 남은 문제와 보장하지 않는 결과를 적습니다.

## 상세 릴리스 노트

### 변경 배경과 목표

이 변경이 필요했던 이유, 해결하려는 사용자 문제와 이번 릴리스의 범위를 설명합니다.

### 기능별 상세

기능별 동작, 경계, 사용자 경험과 내부 계약을 필요한 만큼 하위 제목으로 나눠 설명합니다.

### 설치 및 업그레이드

새 설치, 기존 버전에서의 전환, 마이그레이션과 복구 절차를 기록합니다.

### 호환성과 운영

지원 운영체제·런타임, 권한, 외부 의존성, 운영 주의사항과 남은 제한을 기록합니다.

### 검증 근거

직접 실행해 확인한 테스트, CI, 설치·제거와 호환성 결과를 근거와 함께 적습니다. 실행하지 못한 검증은 통과로 기록하지 않습니다.
