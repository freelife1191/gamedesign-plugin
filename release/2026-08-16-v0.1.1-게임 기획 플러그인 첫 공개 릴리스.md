# v0.1.1 — 게임 기획 플러그인 첫 공개 릴리스

<!-- github-release:start -->

## GitHub 게시용 요약

Game Design Studio와 Game Design Career를 GitHub에 처음 공개한 버전입니다. v0.1.0의 게임 기획·취업 준비 기능을 공개 설치 경로에 올리고, 설치본에서 플러그인과 번들 스킬의 새 버전을 안전하게 확인하는 업데이트 알림 흐름을 더했습니다.

### 주요 변경

- Studio와 Career를 Git 마켓플레이스에서 독립적으로 설치할 수 있도록 공개 패키지와 안내를 정리했습니다.
- 설치된 플러그인과 번들 스킬의 버전을 공개 태그와 비교하는 업데이트 점검 기능을 추가했습니다.
- 같은 업데이트 알림이 세션마다 반복되지 않도록 버전별 확인 상태를 안전하게 저장합니다.
- 프로젝트 기억과 이미지 자산 흐름을 사용자 문서와 시각 자료로 보완했습니다.
- 공개 릴리스에 맞춰 패키지, 가이드, 카탈로그와 설치·제거 수명주기를 다시 검증했습니다.

### 업데이트 안내

v0.1.0 기준점을 사용 중이라면 v0.1.1 이상으로 옮겨 공개 태그와 업데이트 점검 경로를 사용하세요. 처음 설치할 때는 저장소 `README.md`의 Git 마켓플레이스 절차를 따르면 됩니다.

### 검증 요약

- 계약 테스트 342/342 통과
- 사용자 가이드 검증 158건 통과
- Archify 카탈로그, Career·Studio 빌드 정합성, 설치·제거 수명주기 검증 통과

### 알려진 제한

- 업데이트 알림은 새 버전의 존재와 변경 근거를 보여 주지만 자동으로 설치하지 않습니다.
- 용어 승인, 프로젝트 기억 채택, 유료 이미지 생성과 외부 게시는 사용자의 명시적 결정이 필요합니다.
- 생성 결과의 재미, 흥행, 매출, 채용 성과, 법률 준수나 플랫폼 승인을 보장하지 않습니다.

## 상세 릴리스 노트

### 변경 배경과 목표

v0.1.0은 기능과 계약을 한 저장소 안에서 완성한 기준점이었지만 공개 사용자가 설치하고 갱신하는 경로는 아직 마무리되지 않았습니다. v0.1.1은 두 제품의 첫 공개 배포를 목표로 패키지 설명, Git 마켓플레이스 설치 흐름, 세션 시작 시 업데이트 안내와 공개 검증 기록을 정리한 릴리스입니다.

이 버전의 핵심은 “업데이트가 있다”는 메시지를 띄우는 데 그치지 않습니다. 설치된 제품과 번들 구성 요소의 실제 버전을 확인하고, 비교 가능한 공개 태그가 있을 때만 안내하며, 같은 알림을 반복하지 않고, 검사 도중 설치 파일을 바꾸지 않는 계약을 세웠습니다.

### 기능별 상세

#### 첫 공개 설치 경로

- 저장소를 Codex Git 마켓플레이스로 추가한 뒤 Studio와 Career를 각각 설치할 수 있습니다.
- 제품별 패키지는 자신의 스킬, 에이전트, 공유 런타임과 사용자 문서를 독립적으로 포함합니다.
- 설치 후 플러그인 목록과 제품 스냅숏을 확인하고, 제거 뒤에는 격리한 로컬 상태가 남지 않는지 검증합니다.
- 제품 README와 루트 가이드는 설치, 첫 요청, 결과 위치, 내보내기와 문제 해결 순서로 연결됩니다.

#### 업데이트 점검과 세션 알림

세션 시작 시 실행되는 업데이트 점검은 설치된 스위트 버전과 번들 구성 요소를 읽고, 공개 릴리스 정보와 비교해 새 버전이 있을 때만 알립니다.

- 비교 대상이 SemVer로 해석 가능하고 출처가 확인된 경우에만 업데이트 후보로 취급합니다.
- 공개 태그, 제품 버전, 번들 스킬 버전과 생성된 매니페스트 사이의 불일치를 검증 단계에서 거부합니다.
- 네트워크 오류, 응답 시간 초과, 비교할 수 없는 버전과 손상된 캐시는 정상 업데이트처럼 표시하지 않습니다.
- 검사 단계는 읽기 전용이며 설치된 플러그인이나 저장소 파일을 직접 수정하지 않습니다.

#### 알림 반복 억제와 상태 보존

사용자가 이미 확인한 버전은 버전별 상태로 기록해 같은 세션 알림이 반복되는 문제를 줄였습니다. 상태 파일은 잠금과 원자적 교체를 사용하며, 쓰기가 중단됐거나 오래된 잠금이 남아 있으면 완료되지 않은 기록을 정상 상태로 인정하지 않습니다.

- 동일 버전 알림은 한 번만 처리되도록 동시에 들어온 요청의 순서를 정합니다.
- 쓰기 중단 뒤에는 검증된 이전 상태를 복구하고 임시 세대를 정리합니다.
- 손상됐거나 허용 범위를 벗어난 상태 파일은 성공으로 간주하지 않습니다.
- 사용자 위키나 작업 산출물은 업데이트 검사 대상 레퍼런스 코퍼스에서 제외합니다.

#### v0.1.0 기능의 공개 패키징

v0.1.1은 v0.1.0의 핵심 제품 기능을 그대로 공개 설치 경로에 제공합니다.

- Studio: 비전, 시스템, 콘텐츠, 경제, 라이브 운영, 제작 계획, 전문가 검토, 문서 품질, 이미지와 컷씬 흐름
- Career: 직무·공고 조사, 역기획, 포트폴리오, 면접, 성장 계획, 전문가 검토와 내보내기
- 공통: 근거 처리 규칙, 승인형 용어 사전, 프로젝트 기억, 재현 가능한 빌드, Skillstead 기반 시각화와 감사 기록

이 태그에는 Studio 원본 스킬 16개, Career 원본 스킬 15개와 사용자 가이드 Markdown 158개가 포함돼 있습니다.

#### 문서와 시각 자료

프로젝트 기억의 후보·승인·검색·만료 흐름과 이미지 자산의 계획·승인·생성·검토 흐름을 가이드와 도식으로 보완했습니다. 공개 사용자가 내부 테스트 이름을 몰라도 설치 후 첫 작업과 승인 지점을 찾을 수 있도록 루트 README와 제품 문서를 연결했습니다.

### 설치 및 업그레이드

처음 설치할 때는 저장소의 현재 설치 가이드를 따르세요. 이 릴리스 당시의 공개 경로는 Git 마켓플레이스에 저장소를 추가하고 두 제품을 필요한 만큼 설치하는 방식입니다.

v0.1.0에서 옮길 때는 다음을 확인하는 것이 안전합니다.

1. 프로젝트 산출물, 승인된 용어와 프로젝트 기억을 별도로 보존합니다.
2. 설치된 제품이 v0.1.1 공개 태그와 같은 소스를 가리키는지 확인합니다.
3. 새 세션에서 제품과 번들 스킬 버전이 읽히는지 확인합니다.
4. 업데이트 알림이 같은 버전에 대해 반복되지 않는지 확인합니다.

자동 마이그레이션이나 무승인 업데이트는 제공하지 않습니다. 검사 결과가 새 버전을 알려도 실제 설치 변경은 사용자가 선택한 설치 절차에서 수행해야 합니다.

### 호환성과 운영

- Node.js 18 호환성을 고려한 매니페스트 생성과 경로 탐색을 포함합니다.
- 업데이트 점검은 세션 시작 지연을 제한하기 위해 시간 예산을 갖고 실행됩니다.
- 네트워크를 사용할 수 없거나 원격 정보를 신뢰할 수 없으면 업데이트 확인을 건너뛰며, 설치된 기능은 계속 사용할 수 있어야 합니다.
- 업데이트 상태와 잠금 파일은 제품 소스가 아니라 사용자 상태 영역에 저장합니다.
- 별도 바이너리 첨부 파일은 없으며 Git 태그와 설치 패키지가 배포 기준입니다.
