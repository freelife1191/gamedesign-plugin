## 결정

소개 섹션에는 새 도식 한 장만 추가한다. 플러그인 선택, 한 문장 요청 처리와
전체 시스템 구조는 기존 도식이 이미 설명하므로 반복하지 않는다. 새 도식은
유리링 관련 리포트와 다른 게임 기획 자료가 검토 가능한 기획 결과로 바뀌는
과정을 보여 준다.

도식은 `어떤 자료를 참고했나요?`의 자료 설명을 읽은 직후, `자료를 답으로
바꾸는 방식`의 표보다 먼저 배치한다. PNG를 누르면 편집 가능한 SVG가 열리게
한다.

## 전달할 이야기

제목은 `자료를 그대로 답으로 쓰지 않습니다`로 한다. 부제는 원문과 최신 자료를
나누어 확인한 뒤 기획 결과와 사람 검토로 이어진다는 점을 설명한다.

도식의 읽기 순서는 다음과 같다.

1. 원문 49편: 유리링 관련 리포트 6편을 포함한 작성 맥락과 경험을 보존한다.
2. 최근 확인한 1차 자료 16건: 2026-08-11에 확인했으며 바뀔 수 있는 정보는 따로 살핀다.
3. 사실·추론·가정을 나눠 기록하고 확인하지 못한 내용은 `미정`으로 둔다.
4. 기획에 계속 쓸 원칙 7개를 정리해 작업마다 확인할 질문으로 삼는다.
5. 제작 기획 (Studio)과 학습·취업 준비 (Career)로 나뉜다.
6. 기준 기획 결과물에 본문, 근거, 결정과 미해결 항목을 함께 남긴다.
7. 이름을 기록한 검토 담당자가 승인하거나 보류한다. 보류하면 근거나 내용을 수정해
   다시 검토한다.

## 시각 구조

- 캔버스: 1400×900, 2배 PNG는 2800×1800
- 유형: 흐름도
- 노드: 8개
- 입력: `source-docs`, `current-sources`
- 근거 정리: `evidence-boundary`, `core-principles`
- 작업 분기: `studio-work`, `career-work`
- 결과와 검토: `canonical-artifact`, `human-review`
- 실선: 자료 정리와 결과 작성의 기본 흐름
- 점선: 사람 검토에서 근거 구분으로 돌아가는 보류·수정 흐름
- 색상과 글꼴: 기존 README Skillstead 도식의 밝은 회색 바탕, 파랑·보라·초록·
  주황·분홍 강조와 한국어 글꼴 묶음을 따른다.

`humanize-korean` Fast Path로 검수한다.

- 수치 49·6·16·7, 날짜 2026-08-11, 제품명, URL과 파일 경로는 바꾸지 않는다.

## 검증 기준

1. SVG는 1400×900이며 제목과 설명을 가진다.
2. 모든 글자는 16px 이상이고 한글이 깨지거나 잘리지 않는다.
3. 8개 노드와 8개 기본 간선, 1개 점선 보류·수정 간선이 계약과 일치한다.
4. Skillstead `check-svg.mjs`가 오류 0건, 경고 0건으로 통과한다.
5. 정식 Chromium 렌더러가 2800×1800 PNG를 만든다.
6. 맞춤 보기와 원본 크기에서 글자 겹침, 잘림, 왜곡과 약한 화살표가 없다.
7. README에서 PNG를 누르면 같은 이름의 SVG가 열린다.
8. README, 가이드, Archify 카탈로그와 전체 회귀 테스트가 통과한다.
