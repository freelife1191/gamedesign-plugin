# 게임 기획 커리어 문장 윤문

`polish-game-design-writing`은 제공된 커리어 증거와 claim 경계를 바꾸지 않고 한국어 문장 표현만 다듬습니다.

- 직접 호출: `$game-design-career:polish-game-design-writing`
- 결과: 수정본, 검수 기록, 보호 receipt
- 경계: 경험·성과·채용 결과를 만들지 않으며, 사람의 포트폴리오 또는 채용 판단을 대신하지 않습니다.
