# 게임 기획 문장 윤문

`polish-game-design-writing`은 확정된 게임 기획의 의미·보호 항목·사람 결정 상태를 바꾸지 않고 한국어 문장 표현만 다듬습니다.

- 직접 호출: `$game-design-studio:polish-game-design-writing`
- 결과: 수정본, 검수 기록, 보호 receipt
- 경계: 새 규칙·목표·수치·승인 상태를 만들지 않으며, 사람 승인을 대신하지 않습니다.
