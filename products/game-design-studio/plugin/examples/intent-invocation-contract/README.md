# Skillstead intent and invocation contract

This packaged path keeps the relative documentation link in the vendored Skillstead `svg-infographic` README resolvable inside the installed plugin. The complete upstream example is maintained in the [Skillstead repository](https://github.com/kyungseo/skillstead/tree/main/examples/intent-invocation-contract).

Game Design Studio invokes the vendored skill through `skills/svg-infographic/SKILL.md`. Use the Studio visualization skill for game-design source mapping, preset selection, SVG lint, exact 2× rendering, and visual QA.
