# Plan Junior Growth

## Overview

Turn work events into inspectable evidence and bind growth to approved target-role requirements. Treat an unverified target requirement as provisional, not as a hidden assumption.

## Load Reference

Read `../../references/methods/junior-growth.md` before creating quarterly goals or evaluating readiness. Use its exact requirement status and goal record.

## Growth Workflow

1. Inventory approved target-role requirement IDs and their posting sources. Keep desired skills that lack current sources as provisional requirements.
2. Convert project events, feedback, incidents, decisions, and outcomes into evidence records with stable IDs, attribution, source, and verification status.
3. Create quarterly goals. Link every goal to an approved requirement ID; when no approved requirement exists, create a provisional requirement ID and label the goal provisional.
4. Give every goal an observable project, owner, feedback cadence, proof artifact, and re-evaluation decision. Include both target-role depth and adjacent collaboration breadth when supported by requirements.
5. Schedule feedback around inspectable drafts, playtests, handoffs, analyses, or reviews. Do not use activity count as readiness evidence.
6. At each review, choose continue, revise, replace, approve-ready, or retire. Preserve contradictory feedback and missing proof as explicit evidence gaps.

## Integrity Boundary

Do not invent team size, revenue, retention, personal ownership, implementation status, or result. Do not promise promotion, hiring, or readiness from an unverified plan. Missing support becomes a verification task or honest-answer pattern.

## Output Contract

Return the target requirement register, project-event evidence ledger, quarterly goal records, feedback calendar, proof-artifact index, verification tasks, and re-evaluation decisions.

## Completion

Finish only when every quarterly goal links to an approved or provisional requirement ID and contains an observable project, owner, cadence, proof artifact, and explicit re-evaluation decision.
