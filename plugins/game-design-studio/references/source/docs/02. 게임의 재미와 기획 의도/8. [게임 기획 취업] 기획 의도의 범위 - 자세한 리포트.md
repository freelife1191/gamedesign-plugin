## 1. 게임 기획 의도의 범위: 논리적 흐름과 깊이 있는 설명의 중요성
게임 기획서 작성 시, 기획 의도는 단순히 최종 결과만을 나열하는 것을 넘어, 그 결과에 도달하기까지의 모든 논리적 과정을 상세히 설명해야 한다. 이는 기획의 타당성을 확보하고, 다른 사람의 이해를 돕는 데 필수적이다.


### 1.1. 타노스 사례를 통한 기획 의도 분석

- **타노스의 근본적인 의도**: 우주의 자원은 한정되어 있는데 생명체는 너무 많아 자원이 고갈될 것이라는 문제 인식 
- **초기 해결 시도**: 생명체를 학살하며 자원과 생명체의 균형을 맞추려 했으나, 생명체 증가 속도를 따라가지 못함을 깨달음 
- **새로운 해결책 발견**: 인피니티 건틀렛을 사용하면 우주 생명체의 절반을 단숨에 제거할 수 있다는 사실 인지 
- 인피니티 건틀렛** 제작 조건**: 우주에 흩어진 여섯 개의 인피니티 스톤을 모아야 함 
- 인피니티 스톤** 확보 과정**:
  - 네 개의 스톤은 특정 인물들을 통해 확보 
  - 소울 스톤 확보를 위해 사랑하는 딸 가모라를 희생 
  - 마인드 스톤 확보를 위해 지구의 어벤져스, 비전과 대립 
- **타노스의 행동과 의도의 연결**: 타노스의 최종 의도는 자원과 생명체의 균형을 맞추는 것이었으며, 딸을 죽이고 어벤져스를 공격한 것은 그 의도를 수행하기 위한 행동이었음 
- 기획 의도** 설명의 중요성**: 중간 과정만 보면 이해하기 어렵지만, 전체 논리적 흐름을 설명해야 타노스의 의도가 명확해짐 
- **의도에 대한 다양한 해석 가능성**: 좋은 의도였지만 행동이 나빴다는 시각, 혹은 오해의 소지가 있을 수 있음 

### 1.2. 초보 기획자들이 흔히 저지르는 기획 의도 작성 실수

- **딸을 죽인 의도**: 단순히 "소울 스톤을 얻기 위해 재물을 바쳐야 했기 때문"이라고만 작성하면, "소울 스톤이 무엇인데?"라는 의문이 남음 
- **어벤져스를 공격한 의도**: "자원의 고갈을 막기 위해서"라고만 작성하면, 이것이 어벤져스와 무슨 상관인지, 다른 방법은 없었는지 의문이 생김 
- **대표적인 실수 사례**:
  - 강화 실패 시 아이템이 깨지는 규칙의 의도를 "매출을 올리기 위해서"라고만 작성 
  - 이벤트 출석부 제작 의도를 "접속만 해도 보상을 주기 위해서"라고만 작성 
- **실수의 결과**: 이러한 빈약한 기획 의도는 "무슨 상관인지 모르겠다", "비약이 심하다", "근거가 없다"는 피드백을 받게 됨 

### 1.3. 논리적 흐름을 갖춘 기획 의도 작성 방법

- **단계별 의도 나열의 중요성**: 최종 결과에 도달하기까지의 숨겨진 의도들을 순차적으로 전부 나열해야 논리적으로 앞뒤가 맞음 
  - **타노스 사례**:
  - 자원의 고갈을 막기 위해 생명체의 절반을 죽여야 한다 
  - 생명체의 절반을 죽이기 위해 인피니티 건틀렛을 만들어야 한다 
  - 인피니티 건틀렛을 만들기 위해 인피니티 스톤을 구해야 한다 
  - 인피니티 스톤 중 소울 스톤을 얻기 위해 딸을 죽여야 한다 
  - 강화 실패** 시 **아이템** 파괴 규칙**:
  - 매출을 올리기 위해 유저들이 과금하게 만들어야 한다 
  - 유저들이 과금하기 위해 아이템을 갖고 싶게 만들어야 한다 
  - 아이템을 갖고 싶게 만들기 위해 강력하지만 희귀한 무기를 만들어야 한다 
  - 강력한 무기를 희귀하게 만들기 위해 무기 강화를 어렵게 해야 한다 
  - 강화를 어렵게 하기 위해 무기 강화에 많은 돈이 필요하게 만든다 
  - 강화에 돈을 많이 쓰도록 하기 위해 무기 강화 실패 시 깨지게 만든다 
- **단순 나열의 한계**: 위와 같이 단계별로 나열하는 것만으로는 충분하지 않음. 왜 다른 방법은 안 되는지에 대한 설명이 필요함 
  - 다른 방법이 왜 안 되는지에 대한 의문이 무궁무진하게 떠오를 수 있음 
- **이벤트 **출석부** 사례**: "접속만 해도 보상을 주기 위해"라는 의도는 반쪽짜리 기획 의도임 
  - **숨겨진 의도 추적**:
  - 게임이 망하지 않도록 고인물화를 막아야 한다 
  - 고인물화를 막으려면 신규 유저 유입을 늘려야 한다 
  - 신규 유저 유입을 늘리기 위해 뉴비에게 동기 부여를 해야 한다 
  - 뉴비에게 플레이 동기를 주기 위해 쉽게 보상을 받을 기회를 줘야 한다 
  - 결론: 접속만 해도 보상을 주는 이벤트 출석부 제작 
- **신입 기획 지망생의 흔한 실수**: 최종 의도만 작성하거나, 왜 그래야 하는지 모르게 작성하거나, 최초 의도만 작성하여 논리의 비약이 발생함 

### 1.4. 빈약한 기획 의도로 인해 발생하는 문제점

- **추가적인 의문 제기**: "자원과 생명체의 균형을 맞추기 위해 대량 학살과 인피니티 건틀렛 사용 외에 다른 방법은 없는가?"와 같은 의문이 생김 
- **발생 가능한 의문들**:
  - 인피니티 건틀렛이 전능하다면 자원을 두 배로 늘리면 되지 않는가? 
  - 비폭력적인 해결 방법(자원 절약 운동 등)은 없는가? 
  - 범죄자만 죽이는 등 더 나은 방법은 없는가? 
  - 이 문제를 꼭 해결해야 하는가? 그냥 두면 안 되는가? 
- **의문에 대한 반박의 어려움**: 이러한 의문들에 하나하나 반박하려면 기획자는 지치게 됨 
  - 질량 보존의 법칙: 자원을 두 배로 늘리는 것은 질량 보존의 법칙에 위배됨 
  - **시간 및 효율성**: 기술 발전으로 자원을 대량 생산하는 것은 느리고 불확실하며, 전투를 통한 대량 학살도 느림 
  - **불확실성**: 신에게 자원을 늘려달라고 하는 것은 신이 거절할 수 있어 불확실성이 높음 
  - **기준의 모호성**: 나쁜 놈만 죽이거나 특정 종족만 죽이는 것은 기준이 모호함 
  - **무작위성**: 그나마 가장 공평한 방법은 무작위로 죽이는 것 
  - **예상되는 부작용**: 어벤져스 같은 방해 세력이 있을 수 있으나, 자신의 힘으로 이길 수 있다고 판단하여 진행 
- 강화 규칙** 관련 반박 예시**:
  - "강화 비용을 올리면 되잖아, 그게 더 쉽고 빠른 방법 아니야?" 
  - "강화 확률을 낮추면 되잖아, 그것도 쉽고 빠른 방법이야." 
  - "강화 주문서를 비싸게 팔면 되잖아, 그게 매출을 더 올릴 것 같은데." 
- 출석부** 관련 반박 예시**:
  - "접속만 해도 보상을 준다고? 유저들이 과금을 안 할 것 아니야." 
  - "그런 보상을 줘도 게임 접속 안 할 텐데, 효과 있는 거 맞아?" 
  - "출석부 안 만들고 우편함에 보상을 꽂아줘도 되잖아." 
- **반복되는 질문에 대한 대처**: "이런 방법도 있는데 왜 꼭 그렇게 해야 하느냐?"라는 질문에 하나하나 반박하며 기획을 진행하기 어려움 

### 1.5. 기획 의도 설계 시 필요한 습관과 도구

- **스스로에게 질문하는 습관**: "왜 이건 안 돼?"라는 질문을 다각도로 던지며 모순이나 허점을 찾는 습관을 가져야 함 
- 마인드맵 활용: 기획 의도를 설계할 때 마인드맵을 그려 생각의 흐름을 정리하는 것이 도움이 됨 
  - 머릿속 생각만으로 마인드맵을 펼쳐낼 충분한 영향력이 부족할 수 있음을 인지해야 함 
- **연결된 의미 인지**: 당연해 보이는 것들도 자세히 생각하면 모두 의도가 있고, 모든 것에 서로 연결된 의미가 있다는 점을 인지해야 최선의 답을 찾을 수 있음 

### 1.6. 출석부 시스템의 세부 기획 의도 탐구

- **출석부 관련 질문 예시**:
  - 왜 접속만 해도 보상을 줘야 하는가? 
  - 왜 그냥 주지 않고 출석부 화면을 보여준 뒤 주는가? 
  - 왜 스크롤 없이 전체 보상이 한 화면 안에 들어가야 하는가? 
  - 왜 아이템 이름 대신 아이콘과 수량만 표시하는가? 
  - 왜 이미 받은 보상 아이콘을 흐림 처리하거나 체크하는가? 
  - 왜 자동으로 팝업되지 않고 확인 버튼을 누르게 하는가? 
  - 왜 계정 생성 직후가 아닌 튜토리얼 완료 후에 등장시키는가? 
  - 왜 접속할 때마다 매일 첫 화면으로 보여줘야 하는가? 
  - 왜 당일 두 번째 접속부터는 굳이 보여주지 않는가? 
  - 왜 보상받기 버튼을 만들어 누르게 하지 않는가? 
  - 왜 출석 보상을 즉시 주지 않고 우편함으로 보내줘야 하는가? 
  - 왜 연속 출석을 안 해도 리셋하지 않고 보상을 이어서 주는가? 
  - 왜 매월 리셋 방식이 아닌 개별 리셋 방식을 사용하는가? 
  - 왜 특정 기간(예: 28일) 동안 해야 하는가? 
  - 왜 7일과 14일은 안 되는 이유는 무엇인가? 
  - 왜 28일 보상을 다 받았을 때 보상의 가치는 어느 정도인가? 
  - 왜 이러한 아이템들을 출석 보상으로 선정했는가? 
  - 출석 보상을 어떤 순서로 배치했는가? 
  - 특별한 보상을 2개 배치한 이유는 무엇인가? 
  - 세계관과 연관된 의미가 있는가? 
- **이러한 질문에 답할 수 있다면**: 본인의 기획에도 다양한 질문을 스스로에게 하고, 그 답을 기획에 녹여 작성해야 함 

### 1.7. 강화 실패 시 무기가 깨지게 하는 방법의 심층 의도

- **기존 방법의 한계**:
  - 강화 비용을 올리거나 강화 주문서를 비싸게 파는 방법은 사용한 돈과 장비 성능이 비례하여 한계가 있음 
- **강화 실패 시 파괴의 장점**:
  - 무과금**/소액 결제 유저**: 돈을 적게 쓰면서 운이 좋으면 큰 이득을 얻을 수 있다는 환상을 주어 게임을 계속하게 만듦 
  - **핵 **과금 유저: 성공 확률이 독립 시행으로 적용되어 기약 없이 무한하게 돈을 쓰게 만듦 
- **단순 확률 하락이 어려운 이유**:
  - 게임은 확률 공시표를 공개해야 하므로, 유저들이 확률표를 보고 강화 자체를 포기할 수 있음 
- **적절한 확률 제시의 중요성**:
  - "해볼 만하다"는 생각이 들게 하여 라이트 유저도 시도하게 만듦 
  - 실패 시 매몰 비용이 아까워 재시도하게 만듦 
  - 성공 시 행운이 찾아왔다고 느끼며 더 과감한 도전을 하게 만듦 
- **여전히 제기될 수 있는 의문**: "그냥 강화 확률을 낮추거나 주문서를 비싸게 팔면 되지 않겠느냐?" 

### 1.8. 출석부 시스템의 심층 의도와 필요성

- 무과금 유저** 이탈 방지**: 과금 유저와 무과금 유저의 격차가 크면 무과금 유저가 이탈하고, 게임이 소수의 고인물에게만 의존하게 됨 
  - 무과금 초보 유저에게 보상을 주어 접속을 유도 
  - 게임 투자 시간이 길어지면 애착이나 목표가 생겨 과금 유저로 전환될 가능성 발생 
- **과금 유저와의 격차 조절**: 과금 유저도 보상을 받게 하여 무과금 유저와의 격차를 줄이되, 과금 유저가 후회할 만큼 큰 보상은 아니도록 책정해야 함 
- **유저 이탈 지연 효과**: 게임 플레이에 지치거나 바쁠 때, 일일 퀘스트 같은 숙제는 건너뛰더라도 접속 보상만큼은 받고 종료하게 만들어 이탈을 늦춤 
- **출석부 시스템의 추가 목적**:
  - 내일, 그다음 날, 마지막 날의 보상을 시각적으로 돋보이게 하여 다음 접속을 유도 
- **우편함 보상과의 차이점**: 출석판 없이 우편함에 바로 지급하는 것은 출석부의 목적을 달성하기 어려움 
- **출석부 시스템의 필요성**: "그냥 우편함에 꽂아주면 되지 않느냐", "아무것도 안 해도 보상을 주는 시스템이 왜 필요하냐"는 의문이 해소됨 

### 1.9. 다양한 보상 시스템의 개별 의도

- 출석부** 외 보상 시스템**: 오프라인 보상, 일일 무료 뽑기, 상점 무료 상품 구매 등 
- **통합 보상의 비효율성**: 모든 보상을 출석 보상에 통합하면 개발 및 유저 편의성은 좋지만, 각 시스템별 세부 기획 의도를 살리기 어려움 
- **개별 시스템의 의도**: 각각의 시스템을 따로 만든 이유는 각 시스템마다 의도한 세부 기획 의도가 있기 때문 
  - 각 시스템의 의도를 다시 한번 생각해 볼 필요가 있음
